一个任务，一个分支，一个智能体

会话开工所需的一切，以及你读懂它做了什么所需的一切。

每个任务一个 worktree，在智能体启动前就已就绪

从任意基础分支创建。lich 会复制你被 gitignore 掉的 .env* 文件，预留一个开发服务器端口，并运行 .lich/setup-worktree.sh。从尚未提交的改动开始，这些改动也会一起带过去。

评论作为 prompt 回到会话

在 diff 里右键选中的内容，写下哪里不对，准备好之后再把整批评论交给会话。

内联审查 Pull Request

待提交的评论留在你的机器上，直到你提交审查，再通过 gh 发到 GitHub。

智能体之间互相交接工作

你敲的那个 lich 命令，也是一个会话给另一个会话派任务、再读回答案的方式；也可以通过 14 个 MCP 工具。

每种颜色都是一个主题 token。导入一个 JSON 文件，或者从 git 安装一个主题包。

让会话在沙箱里运行

智能体可以在操作系统沙箱里启动：一个全新的 home，机器的其余部分只读，只有它自己的检出目录可写。Linux 用 bubblewrap，macOS 用 sandbox-exec。它不是针对恶意代码的边界。

不丢任何一条线索

Ctrl/Cmd+K 按名称或按会话里说过的话跳到某个会话，还能恢复你在 lich 之外开始的对话。有会话在等你时，桌面通知会告诉你。

一行命令安装

然后打开一个项目，选一个智能体。需要 PATH 上有 git；只有 Pull Request 需要 gh。

Linux x86_64

curl -fsSL https://raw.githubusercontent.com/omartelo/lich/main/install.sh | sh

按你的发行版选择 .deb、.rpm 或 .pkg.tar.zst，并用 checksums.txt 校验。Arch 上：yay -S lich-bin。需要 glibc 2.34+ 和 zenity。

macOS Apple Silicon 和 Intel

brew install --cask lichdotdev/tap/lich

通过 Homebrew；brew upgrade 会装上下一个版本。

Windows x64

scoop install https://github.com/omartelo/lich/releases/latest/download/lich.json

或者用 Releases 里的安装程序，它会原地自我更新。

tarball、便携 zip 和校验步骤见 INSTALL.md。
