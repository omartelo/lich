One task, one branch, one agent

Everything a session needs to start working, and everything you need to read what it did.

A worktree per task, ready before the agent starts

Branch from any base. lich copies your gitignored .env* files, reserves a dev-server port and runs .lich/setup-worktree.sh. Start from uncommitted work and it comes along.

Comments go back as a prompt

Right-click a selection in the diff, write what is wrong, and send the batch to the session when you are ready.

Review a pull request inline

Pending comments stay on your machine until you submit the review, then go to GitHub through gh.

Make it yours

Every color is a theme token. Import a JSON file or install a pack from git.

Run a session confined

An agent can start in an OS sandbox with a fresh home, the rest of the machine read-only and only its checkout writable. bubblewrap on Linux, sandbox-exec on macOS. It is not a boundary against hostile code.

Never lose the thread

Ctrl/Cmd+K jumps to a session by name or by what was said in it, and resumes conversations you started outside lich. A desktop notification tells you when one is waiting on you.

Install it in one line

Then open a project and pick an agent. git on your PATH; gh only for pull requests.

Linux x86_64

curl -fsSL https://raw.githubusercontent.com/omartelo/lich/main/install.sh | sh

Picks the .deb, .rpm or .pkg.tar.zst for your distribution and checks it against checksums.txt. On Arch: yay -S lich-bin. Needs glibc 2.34+ and zenity.

macOS Apple Silicon and Intel

brew install --cask omartelo/tap/lich

Through Homebrew; brew upgrade takes the next release.

Windows x64

scoop install https://github.com/omartelo/lich/releases/latest/download/lich.json

Or the installer from Releases, which updates itself in place.

The tarball, the portable zip and the checksum steps are in INSTALL.md.
